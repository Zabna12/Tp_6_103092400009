1. JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web menjadi interaktif dan dinamis. Kegunaannya adalah untuk menangani klik tombol, memvalidasi formulir, dan mengubah tampilan halaman tanpa harus memuat ulang seluruh halaman.
2. jQuery adalah library JavaScript yang mempermudah penulisan kode untuk mengatur elemen HTML, menangani kejadian (event), membuat animasi, dan melakukan permintaan data ke server dengan kode yang lebih sederhana.
3. JavaScript merupakan bahasa pemrograman yang digunakan untuk membuat halaman web menjadi interaktif, sedangkan jQuery adalah library JavaScript yang mempermudah penulisan kode. JavaScript dapat digunakan tanpa library tambahan, sementara jQuery membutuhkan library jQuery agar dapat digunakan.
